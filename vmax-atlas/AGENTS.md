## VMAX Atlas
- Graph data lives in `public/data/vmax-graph.json`, generated by `tools/extract_vmax.py` (Python AST) — never hand-edit nodes/edges; regenerate from source so nothing is invented.
- Pure logic in `src/lib/vmax/*` (types, graph, layout, categories, store); UI in `src/components/vmax/*` — keeps UI swappable and new categories a one-line registry change.
